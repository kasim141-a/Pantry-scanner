# 🥦 Smart Pantry Scanner

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](https://opensource.org/licenses/MIT)
[![Home Assistant](https://img.shields.io/badge/Home%20Assistant-2024.1%2B-blue.svg)](https://www.home-assistant.io/)

An open-source Home Assistant custom component for AI-powered kitchen inventory management.

## Features
- Pantry inventory tracking
- Expiration monitoring
- Recipe suggestions
- Smart shopping lists
- Waste & savings tracking

## Installation
Copy `custom_components/smart_pantry` to your Home Assistant `config/custom_components/` directory.

## Setup
Go to **Settings → Devices & Services → Add Integration → Smart Pantry Scanner**
